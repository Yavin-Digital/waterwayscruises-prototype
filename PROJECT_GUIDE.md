# Project guide: Waterways Cruises & Events

Review build for Hilton Smith, owner of Waterways Cruises & Events, Seattle (waterwayscruises.com). Mike Montes asked for it on November 9, 2026. Prepared by DPA Branding (mike@dpabranding.com). No-cost comparison piece. The client’s own redesign was not seen and is not discussed.

## Discovery gap

Google `site:waterwayscruises.com` (dossier D08) was blocked. The research brief stayed unsigned for that reason. This build proceeded on Mike’s November 9 request and records the gap in `SCOPE.md` and here. Discovery is not complete. URLs that never appeared in the sitemap, the crawl, or the audit can still be missing.

## How to read the site

Review host: `https://waterwayscruises.clientreview.co` once DNS and the certificate are in place. GitHub Pages serves the `main` branch. `CNAME` is `waterwayscruises.clientreview.co`.

Every page is `noindex, nofollow`. A yellow-bar prototype banner sits on every page. **SEO / AEO Compare** is beside **View Performance Report**. The compare file and the three companion reports state the live 38/64 baseline and leave the prototype unscored. They do not invent a performance score. The banner’s load-time panel measures the open page only.

`seo-aeo-compare-facts.md` is at the repo root and is listed in `_config.yml` `exclude`, so the public URL should 404.
